# Viva pack: Phase 1, Intelligent Agent Mapping (Vendor Matching)

Read in this order. Each file is short and self-contained.

| File | What it covers |
|---|---|
| `01_flow_and_files.md` | The whole pipeline, what each script does, and **which file to run first** |
| `02_features.md` | Every feature, how it is computed, and why it is there |
| `03_linear_regression_mle.md` | Linear regression as Gaussian MLE, why minimising RSS = maximising likelihood, σ², s², β₀, R², the log-likelihood with real numbers, theory vs reality |
| `04_logistic_regression.md` | Why logistic (not linear) regression for classification, the Bernoulli likelihood, why the full model's MLE does not exist, confusion matrix, accuracy/precision/recall/F1 with real numbers |
| `05_how_to_present.md` | A step-by-step script for explaining the project, and why notebooks are used |
| `06_practice_questions.md` | Likely examiner questions with short answers |
| `07_extended_models.md` | Ridge, robust (Huber), Bayesian linear regression, kernels and the kernel trick, Fisher LDA, naive Bayes (generative vs discriminative), Laplace approximation + Bayesian logistic regression, SVMs: why each was added and the real results |
| `00_key_numbers.md` | **Generated by code**: every number used above. If anything disagrees, this file wins |

The graphs are in `../graphs/`: 01–12 cover the Phase 1 models and 13–19 the extended models.
Regenerate everything with `python src/extended_models.py` then `python src/make_viva_pack.py`.

**One caveat to state every time:** the regression target (`expected_score`) and the
200-row pharmacy audit labels are **AI-judged labels, not ground truth**. Human validation
was not done.
